# 发布步骤

这份指南写给你（作者）。标注 **【你来做】** 的步骤必须由你本人操作；标注 **【Claude 来做】** 的步骤由 Claude 完成，但会先征得你同意。

目标：把源码放到 GitHub，把插件发布到 VS Code 应用市场。

1. **【你来做】安装并登录 GitHub CLI。**
   从 https://cli.github.com 下载 Windows 安装包并安装，然后在新开的 PowerShell 窗口里执行 `gh auth login`（GitHub.com → HTTPS → Yes → Login with a web browser），最后用 `gh auth status` 确认登录的是你的账号。

2. **【Claude 来做】创建仓库并推送。**
   Claude 先在 `package.json` 里填写 `repository`、`bugs`、`homepage`，再执行 `gh repo create <用户名>/vscode-web-nav --public --source . --remote origin --push`。
   在你明确同意之前，Claude 不会创建仓库，也不会推送。

3. **【你来做】创建应用市场 publisher。**
   打开 https://marketplace.visualstudio.com/manage ，用微软账号登录，点击 “Create publisher”。必填的只有两项：
   - **Name**：显示名，以后可以改。
   - **ID**：只能用字母、数字和连字符（不能有 `.`），**创建后不能改**。
   其余项都可以留空，建议填上 Support（仓库的 issues 地址）和 Logo（`media/icon.png`，正好 128×128）。

4. **【Claude 来做】（你提供 ID）把 publisher 填进 `package.json`。**
   把第 3 步的 ID 告诉 Claude，Claude 会加上 `"publisher": "你的ID"`。插件的唯一 ID 就是 `你的ID.web-nav`。

5. **【你来做】打包。**
   ```
   npx @vscode/vsce package
   ```
   应该没有任何警告，并生成 `web-nav-<版本号>.vsix`。如果有警告，把输出发给 Claude 处理。

6. **【你来做】在网页上传 vsix。**
   打开 `https://marketplace.visualstudio.com/manage/publishers/你的ID`，点击 “+ New extension” → “Visual Studio Code”，把第 5 步的 vsix 拖进去，然后点 “Upload”。

7. **【你来做】确认已经发布。**
   上传后市场会自动校验，一般需要几分钟。校验通过后，管理页列表中显示版本号且可见性为 Public；打开 `https://marketplace.visualstudio.com/items?itemName=你的ID.web-nav` 能看到插件页面，在 VS Code 扩展视图里也能搜到。

8. **以后发布新版本。**
   - 【Claude 来做】修改 `package.json` 里的 `version`，并在 `CHANGELOG.md` 补充说明。
   - 【你来做】重复第 5 步打包；然后在管理页点击该插件右侧的 “…” → “Update”，上传新的 vsix。

## 附：用命令行发布（可选）

如果想用 `npx @vscode/vsce publish` 一条命令发布（例如以后放进 CI），需要一个 Azure DevOps 的 PAT（个人访问令牌）：

- 在 https://dev.azure.com 新建组织时，必须关联一个 Azure 订阅，否则 “Continue” 按钮点不了。注册 Azure 账号通常需要验证信用卡和手机号。
- 创建 PAT 时，Organization 选择 “All accessible organizations”；Scopes 选择 “Custom defined”，勾选 “Marketplace → Manage”。
- 令牌等同于密码，不要发给别人，也不要提交到 git。
- 用 `npx @vscode/vsce login 你的ID` 登录（按提示粘贴令牌），以后就可以用 `npx @vscode/vsce publish` 发布了。
